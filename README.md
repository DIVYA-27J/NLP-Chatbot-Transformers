# 🤖 AI Chatbot using Hugging Face Transformers

## 📌 Overview
This project implements a conversational chatbot using Hugging Face's DialoGPT model. The chatbot generates human-like responses and maintains conversation flow.

## 🎯 Objective
To build an interactive chatbot using transformer-based NLP models.

## 🛠️ Technologies Used
- Python
- Hugging Face Transformers
- PyTorch

## ⚙️ Features
- Interactive chatbot
- Context-aware responses
- Continuous conversation
- Exit condition support

## ▶️ How to Run
1. Install dependencies:
   pip install transformers torch

2. Run the notebook

## 📊 Sample Output
User: What is AI?  
Bot: Artificial Intelligence is the simulation of human intelligence.

## 📌 Conclusion
The chatbot successfully demonstrates how transformer models can be used to build conversational AI systems.
